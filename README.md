# Vaibhav Verma - Portfolio

A modern, responsive portfolio website built with React showcasing my skills, projects, and experience.

## 🌟 Features

- **Responsive Design**: Optimized for all devices and screen sizes
- **Modern UI**: Clean and professional design with smooth animations
- **Project Showcase**: Detailed display of my work and projects
- **Contact Form**: Easy way to get in touch with EmailJS integration
- **About Section**: Personal information and skills
- **Experience Section**: Professional background and achievements
- **Services Section**: Skills and services offered

## 🛠️ Technologies Used

- **Frontend**: React.js, CSS3, JavaScript (ES6+)
- **Styling**: Custom CSS with responsive design
- **Animations**: Framer Motion
- **Icons**: React Icons
- **Email Service**: EmailJS
- **Routing**: React Router DOM

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/vaibhav-verma-portfolio.git
   cd vaibhav-verma-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm start
   ```

4. Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

## 📜 Available Scripts

### `npm start`
Runs the app in development mode at [http://localhost:3000](http://localhost:3000)

### `npm run build`
Builds the app for production to the `build` folder

### `npm test`
Launches the test runner in interactive watch mode

### `npm run eject`
**Note: This is a one-way operation. Once you eject, you can't go back!**

## 🌐 Deployment

This project is deployed on GitHub Pages. You can view the live site at:
**https://yourusername.github.io/vaibhav-verma-portfolio**

### Deploy to GitHub Pages

1. Install gh-pages package:
   ```bash
   npm install --save-dev gh-pages
   ```

2. Add homepage to package.json:
   ```json
   "homepage": "https://yourusername.github.io/vaibhav-verma-portfolio"
   ```

3. Add deploy script to package.json:
   ```json
   "scripts": {
     "predeploy": "npm run build",
     "deploy": "gh-pages -d build"
   }
   ```

4. Deploy:
   ```bash
   npm run deploy
   ```
